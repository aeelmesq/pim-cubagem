- `evidencias/`: lista de presença digitalizada, infográfico e fotos leves. Fotos só de quem autorizou o uso de imagem. Vídeos e fotos pesadas ficam na pasta compartilhada; link abaixo.

## Modelo do relatório individual

1. Identificação: nome, RA, curso, semestre.
2. Descrição da ação: onde, quando, para quem.
3. Minha participação: o que eu preparei e o que fiz no dia.
4. Contribuição para a comunidade.
5. Evidências: lista do que está anexado.
