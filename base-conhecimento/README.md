# Base de conhecimento — PIM IV: Cubagem de caminhões

Material de apoio do grupo: o que o sistema faz, as regras de cálculo, as decisões de arquitetura e o que falta fazer.

Escopo: projeto acadêmico de estudantes. A ideia é um sistema simples, correto e bem explicado, e não um otimizador de carga profissional.
