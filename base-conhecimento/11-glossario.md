# Glossário

| Termo | Significado |
| --- | --- |
| Baú | Compartimento fechado do caminhão onde vai a carga |
| Bin packing (empacotamento) | Problema de arrumar objetos num espaço usando o mínimo de lugar. Na versão 3D é difícil de resolver de forma ideal |
| Capacidade de carga | Peso máximo de mercadoria que o caminhão pode levar |
| Carregamento | Conjunto de itens que vai num caminhão numa viagem |
| Cubagem | Cálculo do volume ocupado pela carga e comparação com o espaço disponível |
| Fator de aproveitamento | Parte do volume do baú que dá para usar na prática (ex.: 85%) |
| Fator de cubagem | Quantos kg cada m³ "vale" para cobrança de frete (rodoviário: 300 kg/m³) |
| Medida interna | Espaço útil dentro do baú |
| m³ | Metro cúbico: cubo de 1 m de lado, igual a 1.000.000 cm³ |
| Ocupação | Porcentagem do volume do baú usada pela carga |
| PBT | Peso bruto total: caminhão + carga |
| Peso cubado | Volume × fator de cubagem |
| Peso real | Peso medido na balança |
| Peso taxado / para frete | O maior entre peso real e peso cubado |
| VUC | Veículo urbano de carga, caminhão pequeno para áreas com restrição |
| LGPD | Lei Geral de Proteção de Dados (Lei 13.709/2018) |
| Minimização | Princípio da LGPD: coletar só os dados necessários |
| Hash de senha | Forma de guardar senha que não permite recuperar o texto original |
| JWT | Token que o app recebe no login e envia nas chamadas à API |
| Migration | Script versionado que cria ou altera tabelas do banco |
