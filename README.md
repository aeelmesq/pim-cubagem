## Como trabalhar

1. Leia [base-conhecimento/README.md](base-conhecimento/README.md) antes de começar qualquer parte.
2. Tarefas e ordem de trabalho: [base-conhecimento/09-roteiro.md](base-conhecimento/09-roteiro.md). Marque `[x]` quando terminar.
3. Decidiu algo (uma regra de cálculo, um campo novo, uma tela)? Atualize o arquivo da base de conhecimento correspondente, para o trabalho escrito sair dali.
4. Arquivos grandes (vídeo, fotos em alta, zip) não vão para o Git. Ficam numa pasta compartilhada e o link vai no README da entrega.
5. Não coloque senha, CPF ou dado pessoal de ninguém nesta pasta.
